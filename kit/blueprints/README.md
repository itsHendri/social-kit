# Blueprints

What each skill setup can make needs to cover, plus the questions that tailor it. Setup writes the owner's own skill from a blueprint and their answers. It never copies a blueprint as it is.

- `plan-posts.md`: always made. New media becomes dated draft posts, with a copy-ready caption per channel.
- `youtube-package.md`: for long YouTube videos. Title options, description, chapters, pinned comment and the thumbnail.
- `repurpose.md`: for long content. Finds the moments that stand alone and turns them into clips and short posts.
- `review.md`: looks back at what was posted, judged by the owner's own goal, and writes down what worked.
- `your-own.md`: for anything else the owner does by hand every week.
